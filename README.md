# weather-forecasting-using-api
Developed a Weather Forecasting Application using Python and the OpenWeatherMap API to retrieve and display real-time weather information. The application accepts a city name, sends a request to the API, processes the JSON response, and displays details such as temperature, humidity, wind speed, and weather conditions. 
Weather Forecasting App Using Python

Project Description

A simple weather forecasting application developed using Python and the OpenWeatherMap API. The application allows users to enter a city name and retrieve real-time weather information.

Features

- Fetches real-time weather data using the OpenWeatherMap API.
- Displays temperature, humidity, wind speed, and weather conditions.
- Accepts a city name as user input.
- Handles invalid city names and API errors.
- Provides a simple and user-friendly interface.

Technologies Used

- Python
- OpenWeatherMap API
- JSON
- API Integration

How It Works

1. The user enters a city name.
2. Python sends a request to the OpenWeatherMap API.
3. The API returns weather data in JSON format.
4. The application processes the response.
5. Weather details are displayed to the user.
